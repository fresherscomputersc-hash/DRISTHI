Technical Innovation

Architecture: High-Performance Local-First Design

Engineered for extreme reliability, offline execution, and sub-50ms query speeds

The Modern Stack

  • Next.js 15 App Router: Server Components execute directly beside the database. Zero SQL exposure to the client.
  • Embedded SQLite (better-sqlite3): Zero-install, synchronous reads, zero binary engine ceremony, and 100% deterministic demo repeatability.
  • Pre-Aggregated `trip_finance`: Eliminates multi-table runtime joins by indexing expected vs remitted fare per trip during ingestion.
  • Pure TypeScript Core Engines: Zero Python microservice overhead; Holt-Winters and Risk Scoring run in pure typed TS.

Data Flow at a Glance

1. Siloed Sources: ETM tickets + OPRS reservations + GPS waypoints + Workshop logs.
2. Triangulation & Pre-Aggregation: Flattened to 123k trip_finance rows with ₹25 noise buffer.
3. Four Core Engines: Reconcile, Forecast, Risk Score, and Capacity Rebalancer.
4. Explainable UI: Role-based consoles with drill-down evidence drawers and case workflows.

Engine #2

Demand Forecasting: Seasonal Holt-Winters Model

Pure TypeScript additive triple exponential smoothing with weekly cyclicality

Predictive Capabilities

  • Weekly Periodicity (m=7): Captures weekday office peaks and weekend pilgrimage travel (Puri, Konark).
  • 14-Day Hold-Out Backtesting: Calculates Mean Absolute Percentage Error (MAPE) against true hold-out data.
  • 80% Prediction Confidence Bands: Visualizes variance range so planners never plan around single-point guesses.
  • Refusal Policy: If route history is < 21 days, the model refuses to hallucinate and alerts the planner.

Engine #3

Predictive Fleet Maintenance: 0–100 Risk Score

Multi-variate workshop synthesis to stop roadside failures before departure

The Explainable Formula

Risk = 0.30·Service + 0.25·Breakdowns + 0.20·Age + 0.15·Repeats + 0.10·Recency
  • Service Overdue (30%): Kilometers past scheduled 40,000 km overhaul.
  • Breakdown History (25%): Frequency of roadside towing in last 90 days.
  • Vehicle Age (20%): Chassis age & odometer total (>600k km).
  • Repeat Repairs (15%): Same component repaired ≥ 2 times in 30 days.
  • Fault Recency (10%): Work order logged within last 48 hours.

Operational UX

Explainability & Case Actionability

Evidence Drawer Paradigm

Clicking any alert row opens the slide-over Evidence Drawer:

  • Raw Telemetry Rows: GPS waypoints with timestamps and speed records.
  • Rule Trace: The exact boolean logic that triggered the alert.
  • Rupee Impact: Computed based on historical stage occupancy.
  • Confidence Score: Transparent confidence ranking (High / Medium / Low).

Immutable Case Workflow

An alert nobody owns is just a chart. Drishti incorporates an operational case ledger:

  • State Lifecycle: Unassigned → Acknowledged → Under Investigation → Recovered.
  • Officer Assignment: Assigns cases to specific depot recovery officers.
  • Audit Integrity: Cases are stored in a dedicated table; resolving a case never modifies the underlying detection data.
