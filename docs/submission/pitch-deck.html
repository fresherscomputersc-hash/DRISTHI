Core Technical Decisions

  • Next.js 15 Server Components: Zero client-side SQL, zero database credential leaks, instant first paint.
  • Embedded SQLite via better-sqlite3: Ultra-fast synchronous reads without external database processes or cloud risk.
  • Pure TypeScript (No Python): Zero fragile microservice dependencies, 100% deterministic evaluation, shared data types.
  • Zero-Network Guarantee: Functions air-gapped on standard depot hardware with no API keys or internet requirements.

Engine 2: Passenger Demand

Holt-Winters Triple Exponential Smoothing

Predicting corridor boardings with weekly seasonality and dynamic error bands

Mathematical Formulation

ŷ(t+h) = ℓ(t) + h·b(t) + s(t+h-m)

• Level (ℓ): Smoothed baseline boardings
• Trend (b): Week-over-week growth trajectory
• Seasonality (s): 7-day cyclical factor (m=7)

Evaluates 90 days of trip records to generate 7-day rolling corridor forecasts with 80% confidence interval bands.

Operational Safeguards

  • 14-Day Holdout Backtesting: Calculates Mean Absolute Percentage Error (MAPE) against real historical actuals.
  • Refusal to Guess: Automatically raises a "Thin History" warning for corridors with <21 days of history.
  • Capacity Deficit Trigger: Flags corridors where predicted boardings exceed scheduled seating capacity by >15%.

Engine 3: Predictive Maintenance

Explainable 0–100 Breakdown Risk Score

Shifting depot workshops from catastrophic highway failures to proactive bay servicing

Weighted Component Formula

Risk = 0.30·S + 0.25·B + 0.20·A + 0.15·R + 0.10·F
  • Service Overdue (S - 30%): Mileage past scheduled 40,000 km overhaul (max penalty at ≥2,500 km).
  • Breakdown History (B - 25%): Highway breakdowns in past 90 days.
  • Fleet Age (A - 20%): Vehicle age and cumulative odometer.
  • Repeat Repairs (R - 15%): Same component repaired ≥2 times in 30 days.
  • Fault Recency (F - 10%): Workshop visits within past 48 hours.

Operational UX

The Explainability & Evidence Paradigm

"Every alert shows its rows, its rule, and its rupees" backed by an immutable audit trail

The Audit Evidence Drawer

Clicking any alert in the console slides out the detailed Audit Evidence Drawer:

  • Raw Telemetry Rows: Precise GPS breadcrumbs and timestamps verifying bus transit.
  • Deterministic Rule Trace: The exact boolean rule evaluated (e.g., RULE_RC_04: Remittance gap > ₹25).
  • Audited Rupees: Explicit calculation comparing ticket receipts against cashier deposit logs.
  • Personnel Attribution: Conductor ID, vehicle registration, and depot shift supervisor.

Actionable Case Workflow

An alert nobody owns is just a number. Drishti embeds an operational case ledger:

  • Lifecycle: OPEN → ACKNOWLEDGED → UNDER REVIEW → RESOLVED.
  • Depot Delegation: Direct assignment to depot recovery officers with custom notes.
  • Data Immutability: Case notes reside in a dedicated table; resolving a case never mutates the underlying telemetry or financial ledger.
